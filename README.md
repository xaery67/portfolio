# ⚡ BRUTALIST PORTFOLIO // v1.0

A high-contrast, interactive developer portfolio built with **Neo-Brutalism** aesthetics using **Vite**, **Vanilla JS**, **Tailwind CSS**, and **GSAP**.

---

## 🚀 Features

- **Brutalist Design:** High-contrast color palette, thick 4px borders, hard offset shadows (`4px 4px 0 #000`), zero border radius.
- **Interactive Project Showcase:** Dynamic category filters (`Web App`, `Fullstack`, `Creative Dev`, `Tooling`), metric badges, and live demo / source links.
- **Web Audio API Synthesizer:** Built-in retro 8-bit sound effects for clicks, glitches, and form submissions (no external audio files required).
- **Custom Cursor & Interactions:** Brutal crosshair cursor with hover tracking.
- **Chaos Mode & Confetti:** Glitch screen animation, color inversion, and canvas confetti.
- **Dark / Invert Mode:** Instant light/dark theme toggle with `localStorage` persistence.
- **Live Clock & Status:** Real-time millisecond digital clock (WIB) and available-for-work status beacon.

---

## 🛠 Tech Stack

- **Core:** [Vite](https://vitejs.dev/) + Vanilla JavaScript (ES6 Modules)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [GSAP](https://greensock.com/gsap/) + [Canvas-Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Icons:** [Phosphor Icons](https://phosphoricons.com/)
- **Fonts:** [Google Fonts](https://fonts.google.com/) (Space Grotesk, Space Mono, Syne)

---

## 💻 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
